# 拉升时对齐辅助线方案

## 目标
拉升(8 向手柄)改尺寸时,正在移动的那条边接近其他卡片的边/中线(≤6px)时,显示参考线并吸附。

## 核心语义:拉升对齐 ≠ 拖动对齐
- **拖动**:整体平移,吸附改 `x/y`(返回位置)
- **拉升**:只有"移动的那条边"参与,吸附改**尺寸** `w/h`(对侧边不动)
  - `e`(右拉):右边对齐 → 改 `w = oVal - x`,x 不动
  - `w`(左拉):左边对齐 → 改 `x`,同时 `w = (x+w) - x 新`(右边不动)
  - `s`(下拉)/`n`(上拉):同理改 `h` 或 `y+h`
  - 角(ne/nw/se/sw):两条边同时对齐

## 文件变更清单(2 改)

### 1. `useSnapAlign.ts` — snapAlign 加 resizeDir 参数
- `snapAlign` 签名加可选第 4 参:`resizeDir?: ResizeDir`(从 EditableCard 导入类型,或本地定义)
- **没传 resizeDir**:走原逻辑(拖动,改 x/y),完全不变 ✓ 向后兼容
- **传了 resizeDir**:走"拉升分支":
  - x 轴:根据 dir 含 `e`/`w` 决定检测右边/左边;命中后改 `w`(e)或 `x+w`(w),保证对侧不动
  - y 轴:根据 dir 含 `s`/`n` 决定检测下边/上边;命中后改 `h`(s)或 `y+h`(n)
  - 参考线仍正常 push(复用现有渲染)
  - 返回 `{ x, y, w, h }` 完整几何,含吸附后的新尺寸

### 2. `EditableCard.vue` — onResizeMouseMove 接入对齐
- `onResizeMouseMove` 算完原始 w/h/x/y 后,调 `snapAlign(currentGeom, others, 6, rDir)`
- 用返回的吸附后几何覆盖 `resizeW/H/X/Y`
- `endResize` 已有 `clearLines()`(现有代码已清,复用)
- 注意:拉升时 `currentGeom` 要用实时的 `resizeW/H/X/Y` 组装,不是 card 持久化值

### 不改动
- `EditModeView.vue`(参考线渲染层、alignOthers 下传已就绪,拉升复用)
- `useDraggable.ts`(拖动对齐逻辑不变)
- 参考线样式(已加强为明显虚线,拉升复用同一渲染层)

## 关键技术点
1. **单边检测**:拉升时 `getEdges` 仍算 3 条线,但只取 dir 对应的那条参与比距离(如 e 只取右边 = `x+w`)
2. **改尺寸不改位置**:e 方向吸附 `newW = oVal - x`(oVal 是参考边的 x 坐标);w 方向吸附 `newX = oVal`,然后 `newW = startX+startW - newX` 保右边不动
3. **最小尺寸仍 clamp**:吸附后的 w/h 仍要 ≥ 160/120,在 onResizeMouseMove 末尾 clamp(现有逻辑保留)
4. **角拉伸**:ne 同时跑 n+e 两个分支,横竖参考线都能出

## 验证
- vue-tsc 双包零错误
- pnpm dev → /edit:拉右边靠近其他卡片右边/中线 → 出现竖虚线 + 宽度吸附;拉左边 → 左边对齐 + 位置同步;拉下边/上边 → 横虚线;角拉伸 → 同时两条线;松手消失
