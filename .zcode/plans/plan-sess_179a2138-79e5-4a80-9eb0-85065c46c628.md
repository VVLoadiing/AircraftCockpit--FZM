## Form 表单组件体系实现方案

补全一整套表单组件，风格与现有 TechInput/TechSelect/TechSwitch 完全统一（切角 + 主题色聚焦辉光 + 微透底 + BEM 类名 fzm-xxx）。Form/FormItem 内置轻量 rules 校验。

### 新增组件清单（7 个 + 1 个表单容器）

| 组件 | 说明 | 关键 Props |
|------|------|-----------|
| **TechCheckbox** | 复选框（支持 v-model:boolean / v-model:array） | modelValue, label(数组模式值), disabled, indeterminate(半选) |
| **TechCheckboxGroup** | 复选框组（管理多个 Checkbox 的多选） | modelValue:string[], options, disabled |
| **TechRadio** | 单选框 | modelValue, label(该选项值), disabled |
| **TechRadioGroup** | 单选组（管理多个 Radio 互斥） | modelValue, options, disabled, direction |
| **TechTextarea** | 多行输入（与 TechInput 同风格） | modelValue, rows, placeholder, maxlength, showCount |
| **TechSlider** | 滑块（主题色轨道 + 辉光滑块） | modelValue:number, min, max, step, disabled |
| **TechRate** | 评分（科技风星标，主题色辉光） | modelValue:number, max, allowHalf, readonly |
| **TechForm + TechFormItem** | 表单容器 + 表单项（统一布局 + rules 校验） | 见下 |

### Form / FormItem 校验设计（内置轻量 rules）

**TechForm**
- Props: `model`（表单数据对象）, `rules`（校验规则映射）, `labelWidth`, `labelPosition`
- 方法 `validate()` → Promise<.valid>，遍历所有 FormItem 校验，全部通过 resolve(true)，否则 resolve(false)
- 方法 `resetFields()` 重置；通过 `provide` 把 model/rules 传给子 FormItem
- 插槽 `default`

**TechFormItem**
- Props: `label`, `prop`（对应 model 的字段名，必填，用于查 rules）, `required`（视觉红星）
- 从 inject 拿到 form 的 model/rules，依据 `prop` 找到该字段的 rules
- 内置校验规则类型：`required`（必填）/ `min`&`max`（长度或数值范围）/ `pattern`（正则）/ `validator`（自定义函数）
- 校验时机：blur 时自动校验该项；Form.validate() 时统一校验全部
- 校验失败：label 下方红色文字提示，边框变红
- 插槽 `default`（放控件）

校验规则示例：
```ts
const rules = {
  name: [{ required: true, message: '请输入设备名称', trigger: 'blur' }],
  code: [{ required: true, message: '请输入编号' }, { min: 3, max: 10, message: '3-10 字符' }],
  type: [{ required: true, message: '请选择类型' }],
}
```

### 风格统一规范（来自现有组件）
- 微透底 `rgb(var(--primary-rgb) / 0.06)`，聚焦时 `/0.1`
- 边框 `--border-color` → hover `--border-strong` → 聚焦 `--primary`
- 聚焦辉光（标准写法）：`box-shadow: 0 0 0 1px rgb(var(--primary-rgb)/0.4), 0 0 14px rgb(var(--primary-rgb)/0.25)`
- 选中态：`--primary-gradient` 填充 + `--primary` 边 + 外辉光 `0 0 12px rgb(var(--primary-rgb)/0.5)`
- 输入框切角：`var(--notch)` 左上+右下对角 clip-path
- 禁用态：opacity 0.4-0.5
- BEM 类名：`fzm-checkbox` / `fzm-radio` / `fzm-textarea` / `fzm-slider` / `fzm-rate` / `fzm-form` / `fzm-form-item`

### 文件清单（每个组件一个目录：Xxx.vue + index.ts）

**组件库（packages/ui/src/components/）：**
- TechCheckbox/、TechCheckboxGroup/、TechRadio/、TechRadioGroup/、TechTextarea/、TechSlider/、TechRate/、TechForm/、TechFormItem/

**注册（packages/ui/src/index.ts）：**

**文档（apps/playground/src/docs/）：**

- components/*.doc.ts 配置
- registry.ts 注册到「输入与导航」分类

### 实施顺序（分 3 批，便于阶段性验收）
1. **基础选中类**：TechCheckbox + TechCheckboxGroup、TechRadio + TechRadioGroup（4 个组件，结构相似，一起做）
2. **输入/增强控件**：TechTextarea、TechSlider、TechRate（3 个独立组件）
3. **表单容器+校验**：TechForm + TechFormItem（依赖前面组件做综合示例）
4. 全部注册到 index.ts + registry，类型检查，dev 验证，build 通过

### 说明
- Checkbox/Radio 的"组"模式：Group 用 provide/inject 把当前值和 disabled 传给子项，子项用 inject 自动同步，无需手动绑定每个项
- Slider 滑块用原生 input[type=range] 封装 + 自定义主题色样式；Rate 用 SVG 星标 + 点击/键盘交互
- Form 校验是轻量内置（不引第三方），满足常规场景；复杂异步校验用 `validator` 函数自定义
